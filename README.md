Қазақстанның Жалпы Эко-Картасы

Бұл жоба — Қазақстан өңірлеріндегі қайта өңделетін қалдықтарды (пластик, қағаз, батарея, шыны) қабылдайтын орындарды көрсететін интерактивті веб-сайт.

Жобаның мақсаты
Тұрғындарға жақын маңдағы эко-нүктелерді оңай табуға мүмкіндік беру арқылы еліміздегі экологиялық мәдениетті өсіру және қалдықтарды сұрыптауды насихаттау.

 Мүмкіндіктері
- Қазақстанның 18 өңірін/қаласын таңдау:Өңірді таңдағанда карта автоматты түрде сол қалаға ауысады.
- Интерактивті карта:Маркерді басқанда қабылдау нүктесінің мекенжайы мен қабылданатын заттар тізімі шығады.
  Нақты деректер:2GIS картографиялық мәліметтеріне негізделген.

Қолданылған технологиялар
- HTML5 & CSS3: Сайттың құрылымы мен дизайны.
- JavaScript (ES6): Картаны басқару және динамикалық логика.
- Leaflet.js & OpenStreetMap: Интерактивті карта китапханасы.
